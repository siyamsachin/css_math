Units the browser converts for you

Before any math happens, the browser turns every unit into a real size. Then it runs the calculation.

UnitRelative toExampleBecomes
pxFixed size16px16px
remRoot font size (16px)2rem2 × 16 = 32px
emElement’s font size (20px)1.5em1.5 × 20 = 30px
%Parent size (500px)50%500 × 0.5 = 250px
vwViewport width (1000px)5vw1000 × 0.05 = 50px
vhViewport height (800px)10vh800 × 0.10 = 80px
cqwContainer width (600px)7cqw600 × 0.07 = 42px
deg / turnAngles0.25turn= 90deg
1 · You writewidth: calc(100% - 40px);
↓
2 · Browser converts100% = 500px
↓
3 · Browser calculates500px − 40px
↓
4 · One final valuewidth: 460px

In the demos we use cqw (1% of the box width) so a slider can resize the example. On a real page you’d often use vw instead.

                                  Powers & logs · 5 of 5
                                  exp(): multiply by e, again and again
                                  e is a fixed number, ≈ 2.718 (like π ≈ 3.14). exp(x) = e multiplied by itself x times, the same as pow(2.718, x). So exp(2) = 2.718 × 2.718 ≈ 7.39.
                                  
    
                                  Syntax
                                  exp(x) = ex
